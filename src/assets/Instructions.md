# Project Agent-Person Workflow & Rules

## Purpose
This document defines the cooperation, workflow, and rules for collaboration between the Agent (AI) and the Person (user) in the Wild Dragons project.

## Rules

1. Never add any comments.
2. Never add any styles or CSS unless explicitly requested.
3. After completing a task or TODO, always ask for approval or testing before marking it complete and moving further. Use a systematic, step-by-step approach.
4. When creating or editing files, if possible, use formatting predefined in `.prettierrc` and `.editorconfig`.

## Workflow

- The Agent will only proceed to the next step after receiving explicit approval from the Person.
- All changes and additions must strictly follow the rules above.
- The Person may update or expand these rules at any time.
- The Agent will always confirm understanding and compliance with these rules before starting new tasks.
